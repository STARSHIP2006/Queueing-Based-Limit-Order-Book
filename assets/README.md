# Sample execution outputs

These files were generated by running the six experiment scripts with `configs/default.yaml`.
They are illustrative synthetic-data results, not estimates from a real exchange feed.

| Experiment | Main observations |
|---|---|
| 1 — Simulator sanity | 15,038 events over 3,000 seconds; mean bid/ask queue sizes 5.04 / 4.81; estimated bid/ask depletion intervals 16.76 / 14.63 seconds |
| 2 — Parameter recovery | Fits at 600, 1,200, and 1,800 seconds (3,065, 6,062, and 9,058 events respectively); posterior means and 95% intervals are in `experiment_2_parameter_recovery.csv`; trace plots and diagnostics are also included |
| 3 — Bayesian validation | Exact Gamma updates, including the replenishment parameter; grid-quadrature and MCMC summaries for both queue-dependent parameter pairs |
| 4 — Smooth-activity Kalman filter | Log-activity RMSE 0.230; activity-multiplier RMSE 0.132; nominal 95% filtered interval coverage 87.5% |
| 5 — Abrupt-activity stress test | Activity-multiplier RMSE 0.307; low/high classification accuracy 94.6%; mean threshold-crossing response lag 2.86 seconds across 28 evaluated transitions |
| 6 — Posterior predictive | 30 replicated trajectories; predictive summary distributions are in `experiment_6_predictive_summaries.csv` and `experiment_6_posterior_predictive.json` |

The Kalman experiments use known generating structural parameters in controlled synthetic experiments. The true activity path and regime labels are retained only for evaluation; the filter receives transformed event-count observations.

The test suite was run with `python -m pytest -q` and all 14 tests passed.
